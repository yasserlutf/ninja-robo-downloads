## Install

1. Use Android 13 or newer.
2. Download and open Ninja-Robo.apk.
3. Follow Android’s installation prompt.
4. Sign into your Ninja Robo account.

## Updates

The app checks for updates when it opens, at most once every six hours after a successful check. When an update is available, choose Download update in the popup, then approve installation in Android. You can also use Settings → App updates. Later postpones the reminder for 24 hours.

This repository contains public APK downloads and update metadata. It does not contain signing keys or account records.
